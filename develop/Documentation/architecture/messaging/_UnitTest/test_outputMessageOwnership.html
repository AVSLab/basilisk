test_outputMessageOwnership

Check the Python interfaces of module-owned output-message collections.

The module remains alive while its borrowed messages, readers, and recorders are used, as in a normal scheduled simulation. Native tests separately check deletion and allocation-failure cleanup; these tests check SWIG access and stable storage.
