generate_rust_licenses

Generate a deterministic Rust third-party license report.

Defaults produce the report shipped with Basilisk. SDK extension projects can override the manifest, policy, output, project name, and project-license text. The report is derived from the locked Cargo workspace dependency graph. Use --check in automation to verify that the committed report is current. A normal local check skips cleanly when the pinned generator is unavailable; CI uses --require-tool so that the same condition is an error there.
