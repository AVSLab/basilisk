RigidBodyKinematicsNumba

Numba-compatible rigid-body kinematics with Python sequence input support.

Python calls accept numeric lists, tuples, and NumPy arrays. Lists and tuples are converted to float64 arrays before entering compiled code, avoiding Numba’s deprecated Python list reflection. Existing arrays and scalar arguments are passed through unchanged.

Calls from compiled code use registered overloads and the same mathematical implementations. The common Numerical scope and representation limits also apply here. Use arrays or numeric tuples at the outermost compiled function’s boundary. A Python list passed directly to a user-defined @numba.njit function must be converted before that call; a kinematics function inside it cannot perform that outer conversion. Native lists created inside compiled code and numba.typed.List inputs are also supported by the overloads.

Design

RigidBodyKinematics.py is loaded into a private module and its functions are compiled with nb.njit(cache=False, inline='always'). Only that private copy is patched, preserving compiled internal calls without modifying the plain Python module. Public functions are Python wrappers with matching signatures and Numba overloads; they are not Numba dispatcher objects. Compiled callers bypass the Python wrappers and may use Numba’s disk cache.

Requires scipy (for BLAS-backed np.dot / np.linalg.norm inside Numba nopython). A clear ImportError is raised at import time if missing.

RigidBodyKinematicsNumba.BinvEP(Q)

B = BinvEP(Q) returns the 3x4 matrix which relates the derivative of euler parameter vector Q to the body angular velocity vector w.

w = 2 [B(Q)]^(-1) dQ/dt

RigidBodyKinematicsNumba.C2EP()

Q = C2EP(C) translates the 3x3 direction cosine matrix C into the corresponding 4x1 euler parameter vector Q, where the first component of Q is the non-dimensional Euler parameter Beta_0 >= 0. Transformation is done using the Stanley method.
