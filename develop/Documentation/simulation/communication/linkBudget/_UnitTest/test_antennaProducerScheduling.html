test_antennaProducerScheduling

Exercise antenna initialization through the simulation scheduler.

Real spacecraft, ground, antenna, link-budget, downlink and storage modules run on ordered tasks. Delaying either the ground or antenna task exercises the waiting state over multiple timestamps. Reinitializing the same simulation after an altitude change exercises previously written producer messages.

test_antennaProducerScheduling.test_scheduled_antenna_initialization(ground_first, delayed_task)[source]

Validate initialization, waiting, downstream service and reset scheduling.

Validation Test Description

Delayed tasks remain disabled for two ticks while consumers keep running, then resume in producer order. A full simulation reset must subsequently rebuild the atmosphere at the changed altitude on its first scheduled tick.

Test Parameter Discussion

Both link input orders are exercised with normal startup, delayed antenna publication, and antennas publishing before the ground position is ready.

Description of Variables Being Tested

Check CNR, atmospheric and pointing loss, ground normal and position, message timestamps, downlink service and integrated storage removal.

param ground_first:

Whether the ground antenna uses link input one.

param delayed_task:

Producer task to delay, or None for normal startup.
