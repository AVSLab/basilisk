test_sphericalHarmonicsGravityModel

Validate spherical-harmonic table bounds and initialization (issue 1682).

Malformed coefficient tables must produce recoverable errors through direct calls and GravBodyData. Evaluation checks also cover public configuration changes after initialization. Degree-zero results are compared with point-mass gravity, degree-two results with a stored baseline, and reinitialized models with freshly initialized models using the same coefficients.
