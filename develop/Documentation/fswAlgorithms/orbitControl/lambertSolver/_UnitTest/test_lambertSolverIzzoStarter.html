test_lambertSolverIzzoStarter

Check the intermediate Izzo starter and its effect on solver convergence.

test_lambertSolverIzzoStarter.intermediate_problem(lam, fraction)[source]

Place a zero-revolution request along the logarithmic time interval.

fraction = 0 corresponds to the time at x = 0 and fraction = 1 to the parabolic time at x = 1. Values outside that interval exercise the adjacent starter branches.

test_lambertSolverIzzoStarter.izzo_reference()[source]

Load the local reference without colliding with other Support packages.

test_lambertSolverIzzoStarter.test_intermediate_izzo_convergence(direction, lam, fraction)[source]

Resolve the intermediate interval and its boundaries within the validator budget.

An incorrect starter can still converge under the root safeguards, but requests just above the parabolic flight time previously needed six or more refinements and were rejected by the validator’s default policy. Root and residual checks use independent Lagrange and Battin evaluators.

test_lambertSolverIzzoStarter.test_reference_parabolic_boundary(izzo_reference, lam, time_offset)[source]

Keep the actual reference solver finite and accurate on both sides of the boundary.

test_lambertSolverIzzoStarter.test_reference_rounded_parabolic_starter(izzo_reference)[source]

Run refinement when the intermediate starter rounds to exactly one.

test_lambertSolverIzzoStarter.test_reference_starter_logarithmic_interpolation(monkeypatch, izzo_reference, lam, fraction)[source]
