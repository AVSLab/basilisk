test_lambertSolverConvergence.test_alignment_rejection_and_recovery(method, direction, revolutions, angle_degrees)[source]

Reject only the aligned update and recover without resetting the module.

Start with an aligned input, then alternate aligned and valid geometries on the same message and module. Rejected updates must clear both solution and performance slots. Each recovered result must match a fresh module, including when the valid endpoint and flight time change.

test_lambertSolverConvergence.test_independent_branch_validity(method, direction)[source]

Preserve a resolved branch when the other exceeds the evaluator’s resolution.

The long-time right root lies close to x = 1, where small root errors produce large flight-time errors. If resolved, it must meet the independent residual check. A following normal request must resolve both roots.
