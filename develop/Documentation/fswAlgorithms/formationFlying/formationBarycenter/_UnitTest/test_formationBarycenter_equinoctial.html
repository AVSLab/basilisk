test_formationBarycenter_equinoctial

Validate opt-in equinoctial averaging without changing the legacy modes.

The reference recovers classical elements and solves Kepler’s equation by bisection, independently of the module’s direct equinoctial reconstruction. The compact formation construction follows carlo98’s example in issue 1656.

test_formationBarycenter_equinoctial.test_binding_energy_cutoff(element_type, binding_eps, accepted)[source]

Bracket the resolvable elliptic-energy cutoff without an accuracy claim.

With unit radius and gravity, binding is 2-speed**2 and the cutoff is 16*epsilon. The separated samples allow for square-root rounding. Passing the guard at this extreme ellipse only promises finite output.

test_formationBarycenter_equinoctial.test_classical_compatibility(orbits, masses, expected, configuration)[source]

Preserve pre-PR classical position and velocity on both output interfaces.

Fixed reference states were captured using the unmodified C++ module and header from PR 1668’s base commit d0f9832f3b0a40923329c23c2f9255c6c2f1b08b. Input tuples specify semimajor axis, eccentricity, inclination, ascending node, argument of periapsis and mean anomaly. The cases cover unequal weights, angular wrapping, eccentric retrograde motion and low eccentricity. They avoid classical singularities so tight absolute tolerances remain portable: 2 micrometers in position and 2e-8 meters/second in velocity.

Check the omitted selector, explicit CLASSICAL, and the legacy pattern of enabling orbital averaging after a Cartesian update using only useOrbitalElements and mu. Expected outputs are never recomputed with the current module during the test.

test_formationBarycenter_equinoctial.test_equatorial_formation(element_type, factor, equator_offset, eccentricity)[source]

Average unequal members at or near the selected representation’s equator.

Widely separated ascending nodes accompany nearby periapsis longitudes. Each member has a different axis, phase and mass; eccentric members also have different eccentricities. The reference uses the prescribed classical elements, avoiding recovery of undefined angles from Cartesian states. Both output interfaces must match the reference in position and velocity.

test_formationBarycenter_equinoctial.test_equinoctial_component_cancellation(element_type, factor, cancelled_components)[source]

Recover a circular or equatorial mean from nonsingular member orbits.

The masses have ratio 1:3. For each cancelled component pair, the first member has three times the magnitude and the opposite direction to the second. Uncancelled components are identical, and both mean longitudes are equal. Thus the expected averaged orbit is known analytically without using weighted_reference or recovering singular classical angles. Test eccentricity and inclination cancellation separately and together, including both position and velocity on both output interfaces.

test_formationBarycenter_equinoctial.test_excluded_pole_cutoff(element_type, tilt_eps, accepted)[source]

Reject at/below the pole cutoff and recover a state just outside it.

Cartesian construction avoids subtracting a tiny tilt from pi. Its unit angular momentum has transverse magnitude tilt_eps*epsilon to floating precision and points toward the selected representation’s excluded pole.

Bracket the 64-epsilon circular-resultant cutoff with equal near-opposites.

test_formationBarycenter_equinoctial.test_multiple_updates_refresh_navigation_and_mass(element_type)[source]

Check six scheduler updates with changing navigation and mass messages.

Three unequal ellipses share one semimajor axis and advance analytically at the common two-body mean motion. Both output forms and sample times must match a fresh independent reference at every step. The masses change halfway through to expose stale inputs or uncleared averaging sums. This tests scheduled message integration, not a numerical dynamics integrator.

test_formationBarycenter_equinoctial.test_near_radial_cutoff(element_type, transverse_eps, first_guard)[source]

Above the radial guard, an unrepresentable ellipse must still be rejected.

These almost-radial unit states have eccentricity rounding to one even just above the angular-momentum cutoff. The first guard rejects values at/below its cutoff; the later elliptic-elements guard rejects the rest. Crossing this guard alone must not turn an unresolved ellipse into a valid one.

test_formationBarycenter_equinoctial.test_reported_compact_formation(phases, element_type)[source]

Require an independent state reference and a 1 cm locality budget.

Each member has nonzero eccentricity and non-equatorial inclination, so its classical elements can be recovered without a singular-angle choice. The reference then averages known elements and reconstructs through the separate bisection/rotation path, not the module’s plane equations. The centimetre budget applies only to these reported 100 m formations; it is not an equality requirement for arbitrary orbital and Cartesian means.

test_formationBarycenter_equinoctial.test_runtime_selection(initial_type, selected_type)[source]

Observe every orbital-selector transition before and after an update.

Two equal-mass members share axis, eccentricity, inclination and mean anomaly, with symmetric offsets in ascending node and periapsis. Thus the classical reference uses the midpoint angles exactly. Equinoctial references use the independent element-average and classical-rotation helper. All three references differ in both position and velocity.

Initialize with one choice, select another before the first update, then switch back after that update. Each C and C++ output must match its own reference without another Reset, detecting a choice cached at either initialization or the first update.
