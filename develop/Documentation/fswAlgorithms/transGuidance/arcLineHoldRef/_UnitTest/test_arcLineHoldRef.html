test_arcLineHoldRef

Unit tests for the fixed arc-line-hold translation reference.

test_arcLineHoldRef.test_invalid_durations(setting, value)[source]

Reject timing configurations that make the reference undefined.

Validation Test Description

Reset a module with a nonpositive transition or deceleration duration, or with a nonpositive circle-plus-transition duration.

Description of Variables Being Tested

The three maneuver timing parameters must satisfy the module’s reset constraints.

test_arcLineHoldRef.test_invalid_endpoints(setter, endpoint, name)[source]

Reject endpoints that would cause a jump or lack a finite position.

Validation Test Description

Set off-axis, malformed, and non-finite blend or final endpoints before reset and verify that configuration fails explicitly.

Description of Variables Being Tested

blendEndPosition and finalPosition must be finite three-component vectors with zero inertial x and z components.

test_arcLineHoldRef.test_nonfinite_trajectory_parameters(setter, name, value)[source]

Reject non-finite radii and phase durations during reset.

Validation Test Description

Set each scalar trajectory parameter to NaN or either infinity and verify that reset raises BasiliskError identifying the parameter.

Description of Variables Being Tested

radius, tCircle, tTransition, and tLinear must be finite before the module computes the trajectory boundary states.

test_arcLineHoldRef.test_output_across_phases()[source]

Verify the published reference switches phases and remains at the hold.

Validation Test Description

Evaluate the output message in each phase, at the phase boundaries, and after the maneuver ends.

Description of Variables Being Tested

The TransRefMsg position, velocity, and acceleration fields match the selected phase and the final stationary reference.

test_arcLineHoldRef.test_phase_boundary_continuity()[source]

Verify position, velocity, and acceleration join at every phase boundary.

Validation Test Description

Compare the analytic states on both sides of the arc-to-blend, blend-to-deceleration, and deceleration-to-hold boundaries.

Description of Variables Being Tested

Position, velocity, and acceleration references are continuous.

test_arcLineHoldRef.test_phase_derivatives(phase)[source]

Verify the reported velocity and acceleration are time derivatives.

Validation Test Description

Compare analytic derivatives with centered finite differences at an interior point of each moving phase.

Description of Variables Being Tested

Velocity is the derivative of position, and acceleration is the derivative of velocity.
