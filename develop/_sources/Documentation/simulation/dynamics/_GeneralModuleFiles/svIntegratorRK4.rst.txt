Classical fourth-order Runge--Kutta integrator. It supplies the four-stage tableau
to ``svIntegratorRungeKutta``, which handles flat storage, stage evaluation, special
state updates, and rollback. See :ref:`integratorArchitecture` for the shared
integration lifecycle.

The module
:download:`PDF Description </../../src/simulation/dynamics/Integrators/_Documentation/Basilisk-Integrators20170724.pdf>`
contains further information on this module's function,
how to run it, as well as testing.
