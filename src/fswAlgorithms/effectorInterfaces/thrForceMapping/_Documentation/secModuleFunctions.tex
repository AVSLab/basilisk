\section{Module Functions}
This module has the following functions:
\begin{itemize}
	\item \textbf{Read in the thruster and spacecraft configuration}: When reset the module reads in the thruster locations, force directions and maximum thrust values, as well as the spacecraft center of mass.  The control axes $\hat{\bm c}_{j}$ are normalized, and a warning is logged if any two control axes are not orthogonal.  On every update the module reads the current spacecraft center of mass and recomputes the thruster moment arms.
	\item \textbf{Compute the thruster force solution}: With each update call the module forms the allocator target $\bm L_r$.  For on-pulsing, this is the input torque $\bm L_{\text{cmd}}$; for off-pulsing, the nominal torque $[D]\bm F_{\text{max}}$ is subtracted first.  The module reduces this target onto the control axes and computes a minimum norm solution for the signed force commands $\bm F$.  The solution can also produce torque outside the controlled subspace.  If {\tt use2ndLoop} is set or off-pulsing is used ({\tt thrForceSign} $= -1$), the 2-stage solution is used to enforce the desired force sign.
	\item \textbf{Evaluate the torque angle error}: The angle $\theta_{\bm\tau/\bar{\bm L}_{r}}$ between the saturation-clipped torque contribution $\bm\tau = [D]\bm F_{\text{clip}}$ and the reduced allocator target $\bar{\bm L}_{r}$ is evaluated in body frame components, and is stored in {\tt outTorqAngErr}.  In off-pulsing mode, this compares the change from nominal torque with the compensated target.
	\item \textbf{Scale the thruster forces if saturated}: If this angle is larger than {\tt angErrThresh}, the thruster forces are scaled such that no thruster exceeds its maximum thrust.
	\item \textbf{Output the thruster force commands}: The resulting thruster forces are written to the thruster force output message.
\end{itemize}

\section{Module Assumptions and Limitations}
The module assumes all thrusters in the configuration message are operating and available.  Thruster locations, force directions, and maximum thrust values are cached until the next module reset.  The spacecraft center of mass is read from {\tt vehConfigInMsg} on every update, so changes to {\tt CoM\_B} do not require a reset.  Up to three control axes are supported, and these must be orthogonal for the reduced torque $\bar{\bm L}_{r}$ to be valid.
