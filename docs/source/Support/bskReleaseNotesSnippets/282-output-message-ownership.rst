- Dynamically allocated output messages in environment models, dynamics effectors, controllers, and device/visualization modules now use private ``std::unique_ptr`` storage. Public output-message vectors, Python indexing, subscriptions, and recorders remain available. This fixes missing cleanup in several modules and releases partially constructed output collections after allocation failures. See :ref:`bskOutputMessageOwnership` for lifetime requirements; compiled extensions using the changed module layouts must be rebuilt for SDK extension ABI version 3.
