- Simulation worker records now use ``std::unique_ptr`` and own their ``std::thread`` by value. Shutdown joins workers before releasing their state or changing process assignments, including exception cleanup. Normal Python thread configuration and simulation APIs are unchanged; the internal ``threadList`` and ``threadContext`` ownership fields are no longer exposed in Python. C++ code accessing these fields must use the new owning types, and compiled extensions must be rebuilt against extension ABI version 3.
- Added :ref:`bskPrinciples-13`, a tutorial on configuring independent processes for multiple worker threads, with a runnable example and guidance on assignment, reinitialization, and shutdown.
- ``SimThreadExecution::requestStop()`` requests shutdown and wakes an idle worker once. ``killThread()`` remains a compatibility alias, and repeated stop requests no longer add semaphore releases. Pool shutdown continues to signal every worker before joining any of them.
