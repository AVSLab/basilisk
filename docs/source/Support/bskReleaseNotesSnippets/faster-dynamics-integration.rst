- Reworked the fixed-step Runge-Kutta integration path (the shared ``svIntegratorRungeKutta`` base used by :ref:`svIntegratorEuler`, :ref:`svIntegratorRK2`, and :ref:`svIntegratorRK4`) to reuse pre-sized per-state buffers across Runge-Kutta stages instead of rebuilding a hashed ``ExtendedStateVector`` and heap-allocating new state matrices on every stage, cutting per-step dynamics integration overhead with no change to the computed results. The adaptive (:ref:`svIntegratorRKF45`, :ref:`svIntegratorRKF78`) and stochastic integrators are unaffected.
- Removed per-call heap allocations from :ref:`reactionWheelStateEffector`'s ``computeDerivatives`` by reusing sized member buffers instead of allocating new ``Eigen::MatrixXd`` values on every Runge-Kutta stage.
- Replaced several hub-state reads that copied an ``Eigen::MatrixXd`` (``StateData::getState()``) with a reference read (``StateData::getStateReference()``) in :ref:`thrusterDynamicEffector`, :ref:`dragDynamicEffector`, :ref:`facetDragDynamicEffector`, :ref:`facetSRPDynamicEffector`, :ref:`radiationPressure`, and :ref:`MtbEffector`, removing an allocation from each call with no change in the values read.
- Fixed the Release build configuration so it compiles at ``-O3`` (CMake's default for Release) instead of being silently downgraded to ``-O2`` by an explicit flag in ``src/CMakeLists.txt``.
