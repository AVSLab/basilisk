- Reworked the fixed-step Runge-Kutta integration path (the shared ``svIntegratorRungeKutta`` base used by :ref:`svIntegratorEuler`, :ref:`svIntegratorRK2`, and :ref:`svIntegratorRK4`) to reuse per-state buffers across Runge-Kutta stages instead of rebuilding a hashed ``ExtendedStateVector`` and heap-allocating new state matrices on every stage, cutting per-step dynamics integration overhead with no change to the computed results. Buffers allocate on first use and may allocate again when the registered states or the dimensions of states or derivatives change.
- Removed per-call heap allocations from :ref:`reactionWheelStateEffector`'s ``computeDerivatives`` by reusing sized member buffers instead of allocating new ``Eigen::MatrixXd`` values on every Runge-Kutta stage.
- Replaced internal read-only state copies with reference reads across BSM effectors, :ref:`spacecraftChargingDynamics`, and MuJoCo scene, controller, noise, and linear-system modules. This removes temporary matrix allocations while preserving owning snapshots where needed; the copy-returning ``StateData::getState()`` and ``getStateDeriv()`` APIs and Python behavior remain unchanged.
- Restored CMake's compiler-specific default Release optimization by removing the explicit ``-O2`` override in ``src/CMakeLists.txt`` (GitHub issue 1586).
- Added :ref:`coding guidance <codingGuidelines>` for internal C++ state reference reads, intentional owning copies, reference lifetime, and Eigen aliasing; the copy-returning accessors remain supported without deprecation.
- Extended buffer reuse to adaptive Runge-Kutta integration, including :ref:`svIntegratorRKF45` and :ref:`svIntegratorRKF78`, to avoid rebuilding hashed state containers during trial steps and error estimation. The existing embedded solutions, step acceptance, tolerance precedence, and componentwise error control are preserved. Buffers allocate on first use and may allocate again after state layout or dimension changes.
- Reused noise-source routing and local increment buffers across all native stochastic integrators, with cache refresh after object, state, noise-count, or shared-noise registration changes between integration calls. Euler–Maruyama also avoids redundant derivative and diffusion maps for ordinary states while retaining custom virtual derivative setter behavior. Noise sequences and virtual propagation are preserved; the existing noise-generator and propagation interfaces may still allocate.
- Reused owned state snapshots, drift and sparse diffusion stages, weighted sums, and noise scratch vectors in Euler–Heun, RKMil, SRIW1/SOSRI, and SRA1/SOSRA. Stage storage allocates on first use and may resize after registration or matrix-dimension changes, while retaining noise draws, stage evaluation times, and virtual state propagation. Added ``StateData::getStateDiffusionReference(index)`` for internal C++ reads; the copy-returning diffusion accessor remains supported.
- Extended stage-buffer reuse to the weak stochastic W2Ito1/2, DRI1/DRI1NM, RI1/3/5/6, RS1/2, SIEA/SMEA/SIEB/SMEB, and RDI1WM integrators, including cross-noise snapshots and reusable pseudo-step vectors. Noise sampling, stage evaluation times, and sequential virtual propagation are preserved. Buffers allocate on first use and may allocate again after topology, matrix-dimension, or DRI mixing-mode changes.
