- :ref:`constrainedAttitudeManeuver` checks planner inputs, pointing cones, and grid refinement (``2 <= N <= 20``). Both searches report when they stop before reaching the goal, and replanning discards stale references (#1703, #1704).
- Maneuver references now start at the reset epoch, preserve endpoint rates across MRP shadow changes, and reject fits that may add a full turn between waypoints. The :ref:`constrainedAttitudeManeuver` User Guide includes a worked example and explains how to check cone clearance between waypoints.
- :ref:`BSpline` validates waypoint timing, endpoint conditions, and weighted fits, and evaluates short final knot spans correctly. Planner refits require finite waypoint attitudes. Only standalone ``BSpline.approximate()`` accepts missing coordinates at zero-weight interior waypoints with explicit times.
- Python ``NodeList`` retains appended Python-owned nodes and rejects copies of grid-backed paths. Python Eigen bindings accept empty dynamic column vectors and preserve the shape of empty two-dimensional NumPy ``ndarray`` inputs.
