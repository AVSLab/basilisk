- :ref:`tleHandling` ``satTle2elem()`` now accepts the keyword-only option ``on_error="skip"`` to skip complete sets that fail validation or numerical conversion, including epoch overflow and division by zero, with a printed warning and return the readable sets. The default, ``on_error="raise"``, preserves the existing behavior of raising the first record error immediately. In skip mode, the first error is raised if every attempted set fails. File-level format checks can still reject the entire file in either mode.
