- Added numeric input validation to :ref:`lambertSolver`: nonfinite or nonpositive flight time and gravity, and endpoint vectors with nonfinite components or zero/nonfinite computed norms now raise ``BasiliskError`` before solving. Alignment thresholds must be finite and strictly between 0 and 90 degrees; rejected setter values preserve the previous configuration. A componentwise roundoff bound rejects parallel and antiparallel endpoints even when normalization leaves a tiny nonzero cross product. Alignment rejection precedes geometry and flight-time scaling to avoid invalid square roots and division by zero.
