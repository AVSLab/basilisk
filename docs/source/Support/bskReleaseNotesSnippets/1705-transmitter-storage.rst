- ``SimpleTransmitter`` and ``SpaceToGroundTransmitter`` publish zero baud with an empty partition name while the selected storage input is unavailable. A reset, a call to ``addStorageUnitToTransmitter()``, or an observed loss or change of storage source discards any partial packet. Scheduled updates with the device commanded off add no bits to the packet, so partition changes can occur later than in earlier releases. The first enabled update resumes an unfinished packet if the same storage source remains available, its partition still holds data, and ground access is available when required. Suspending the task leaves the scheduling gap in the next update interval. ``SpaceToGroundTransmitter`` accepts access from any connected ground station (#1705).
