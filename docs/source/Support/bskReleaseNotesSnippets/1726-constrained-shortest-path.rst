- Added opt-in ``useShortestPath`` to :ref:`constrainedAttitudeManeuver` distance planning. It uses a consistent rotation-angle lower bound and searches to completion for minimum accumulated MRP edge distance on the generated graph. The existing heuristic remains the default, search/path storage grows dynamically, and ``expandedNodeCount`` reports search work. The option does not guarantee minimum control effort or cone clearance along the fitted reference (#1726).
- C++ callers of :ref:`constrainedAttitudeManeuver` should use ``NodeList::list.data()`` when passing its entries as a raw pointer. ``list`` is now a ``std::vector<Node*>``; indexed access and Python list methods are unchanged.
- Added an optional alternate-start comparison to :ref:`scenarioAttitudeConstrainedManeuver`, with a unit-sphere MRP path overlay and a table of grid distance and node expansions for the default and shortest-path heuristics. Existing scenario calls retain effort-based planning (#1726).
