- Added standard CPython 3.15 support while retaining Python 3.9 through 3.14. Python 3.15 uses NumPy 2.5.2 or newer and Numba 0.68 for examples and development; older interpreters retain their dependency ranges. Native message bindings explicitly target the NumPy 1.24 C API so Python 3.15-built wheels remain compatible with NumPy 1.24.4 on older interpreters. Updated source-build CI and wheel tooling, and moved the existing wheel installation checks to Python 3.15.
