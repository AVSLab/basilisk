- Fixed :ref:`opNavPoint` building ``sigma_BR`` from a principal rotation axis in camera frame components. The axis, including the 180 degree fallback axis, is now mapped into body frame components with ``sigma_CB`` from ``cameraConfigInMsg``, so the reference attitude points ``alignAxis_C`` at the target for any camera mounting. The module variable ``eHat180_B`` is renamed to ``eHat180_C``, and ``opNavMnvrVec`` is now in body frame components.
- Fixed :ref:`opNavPoint` discarding the saved heading of an image taken at simulation time 0 on the next update, and ignoring a valid image for one update when it arrived exactly ``timeOut`` seconds after the previous one; with the default ``timeOut`` of zero, valid images were never used. A valid image is now always used immediately, and the saved heading is reused until ``timeOut`` seconds have passed without a valid image. The module variable ``currentHeading_N`` is renamed to ``savedR_BN_N``, as it stores the last measured position ``r_BN`` in inertial frame components rather than a heading.
- Fixed :ref:`opNavPoint` retaining valid messages indefinitely and changing their saved inertial heading as the spacecraft rotates. Valid measurements are now consumed once per increasing message write timestamp; retained messages expire normally. Producers must timestamp new measurements when writing them.
- Fixed :ref:`pixelLineConverter`, :ref:`horizonOpNav`, and :ref:`faultDetection` republishing retained measurements as fresh valid outputs and preventing downstream guidance timeout. Each input now requires an increasing message write timestamp; outputs and their timestamps are preserved between input writes so slower consumers can read the last result. Fault detection applies its modes only to fresh valid inputs in the current update.
