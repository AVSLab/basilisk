- ``DynamicObject`` now owns its integrator through ``std::unique_ptr``. Python ``setIntegrator()`` calls and ``integrator`` attribute access remain available, including scripts that explicitly disown a new integrator before installation; attribute assignment transfers ownership, and reinstalling the active integrator is safe. Custom C++ dynamics classes that assign raw pointers directly to ``integrator`` must use ``setIntegrator()`` instead. The changed C++ ownership contract increments the SDK extension ABI to version 3; compiled extensions must be rebuilt.
- C++ callers can pass ``std::make_unique`` results or move an existing ``std::unique_ptr<StateVecIntegrator>`` into ``DynamicObject::setIntegrator()``. The raw-pointer overload and Python ownership-transfer interface remain supported; rejected replacements are consumed without replacing the active integrator.
