- Added :ref:`accuracyComparison`, which compares Basilisk orbit propagation against GMAT and Orekit for zonal and tesseral gravity, Sun and Moon third-body forces, solar radiation pressure, and NRLMSISE-00 drag. The scripts that generate the GMAT and Orekit reference ephemerides and run the comparison are in ``benchmarks/accuracyComparison``, and the page explains how to reproduce the results.
- Fixed the gravity effector extrapolating the planet orientation with a first-order update of the matrix elements, which is not orthonormal. The orientation is now advanced as a rotation about the planet angular velocity. Before, a SPICE-driven planet distorted even a point-mass field by a relative error of order :math:`(\omega\,\Delta t)^2` of the time since the planet message was written.
- Fixed the environment modules :ref:`atmosphereBase` (including :ref:`msisAtmosphere`, :ref:`exponentialAtmosphere`, and :ref:`tabularAtmosphere`), :ref:`windBase`, :ref:`magneticFieldBase`, :ref:`eclipse`, and :ref:`solarFlux` evaluating the spacecraft state of the previous step. The spacecraft position is now advanced to the middle of the interval the next spacecraft update integrates. Stale messages that were written before the previous module update are not extrapolated. This removes a step-size dependent error, for example in the solar radiation pressure shadow entry and exit times.
- Added ``setPlanetPolarRadius()`` and ``getPlanetPolarRadius()`` to :ref:`atmosphereBase` to compute the altitude, and the latitude in :ref:`msisAtmosphere`, above an oblate ellipsoid. The default remains a sphere.
- Added ``setUseApparentSolarTime()`` and ``getUseApparentSolarTime()`` to :ref:`msisAtmosphere` to add the equation of time to the local solar time input of NRLMSISE-00. The default remains the mean solar time.
- Fixed ``PCPF2LLA()`` returning an altitude that was wrong for a position exactly at a pole of an oblate planet, where the equatorial component is zero.
