- Windows optional-wheel packaging in Basilisk 2.11.x and 2.12.x can reject core and opNav wheels built with different compatible MSVC versions during GitHub runner-image updates. The packager now distinguishes MSVC compiler provenance from ABI compatibility while retaining checks for architecture, runtime settings, type layouts, and shared runtime DLLs. A differing shared runtime is accepted when the core provides an equal or newer release DLL of the same architecture. Previously, rebuilding both inputs with a matching toolchain was the workaround; rerunning packaging with the same mismatched inputs did not help.
