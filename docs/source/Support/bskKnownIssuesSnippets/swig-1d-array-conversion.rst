- In Basilisk 2.12.2 and earlier, failed Python numeric conversions or sequence operations during one-dimensional C-array assignment could overwrite the destination, mask the original exception, or leak references. Sequences that grew while being read could also exceed the checked array bound, including in arrays of wrapped structs. The converters now stop on errors before assignment, release acquired references, bound iteration by the validated length, and reject null pointer elements. On affected releases, use ordinary lists or tuples within the declared capacity, validate numeric elements before assignment, and supply valid wrapped objects for struct arrays.
