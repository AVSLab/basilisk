- In Basilisk 2.12.2 and earlier, malformed WMM coefficient records could reuse values from a preceding line and silently change the computed magnetic field; negative degree/order indices could write outside coefficient arrays, and oversized integers could wrap into valid indices (issue #1691). The WMM reader now validates integer conversions, parsed fields, and index bounds, and failed loads release the partial model and stop initialization. On affected releases, use an unmodified official WMM coefficient file and validate any custom file before loading it.
