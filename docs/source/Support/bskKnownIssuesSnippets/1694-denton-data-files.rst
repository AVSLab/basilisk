- In Basilisk 2.12.2, :ref:`dentonFluxModel` does not check numeric reads from its electron and ion data files. Truncated or malformed files can leave table entries uninitialized or retain values from an earlier load, producing incorrect fluxes without an error (#1694). Initialization now checks every required value, including unused statistics, and raises ``BasiliskError`` with the file path and value number on failure. On affected versions, use complete, unmodified Denton data files and replace any damaged copies.
