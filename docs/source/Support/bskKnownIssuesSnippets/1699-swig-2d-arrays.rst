- In Basilisk 2.12.2 and earlier, assigning malformed or oversized nested sequences to two-dimensional C arrays from Python could crash or corrupt memory; smaller inputs could copy uninitialized values, and failed element conversions could still overwrite the destination (issue #1699). The shared SWIG conversion now validates both dimensions and row consistency, propagates errors before assignment, and zero-pads smaller rectangular inputs. On affected releases, supply fully populated rectangular arrays matching the declared dimensions, with every element convertible to the destination type.
